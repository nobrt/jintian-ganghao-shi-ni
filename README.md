# 《今天，刚好是你》

一个可直接打开的单页生日祝福网站原型。无需构建工具：双击 `index.html`，或通过任意静态服务器打开即可。

## 替换私人素材

- 将照片放进 `assets/`，命名为 `photo-01.jpg`、`photo-02.jpg`、`photo-03.jpg`；或在 `index.html` 内更新对应占位说明和路径。
- 将环境音乐放进 `assets/ambient.mp3`。页面不会自动播放，访客点击右上角 `SOUND OFF` 后才会播放。
- 文案、日期、年份和署名均可直接在 `index.html` 修改。

未提供照片时，照片区域会保留抽象胶片质感占位画面，不影响页面运行。
